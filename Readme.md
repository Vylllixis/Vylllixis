## About me

I'm a French software developer working at the intersection of
**software engineering, application modernization, and industrial R&D**.

Currently working at **Mirion Technologies** as part of a work-study
program while pursuing my studies at **ESGI**, I contribute to the
improvement and modernization of existing software in demanding
technical environments.

I enjoy understanding how systems actually work, identifying their
weak points, and making them more maintainable, reliable, and efficient.

My approach is straightforward:

- **Understand before changing.** Explore the existing system and its constraints.
- **Solve the actual problem.** Prefer useful, measurable improvements over unnecessary complexity.
- **Build for maintainability.** Write code that remains understandable as a project evolves.
- **Respect the existing system.** Modernize without losing essential behavior.
- **Keep learning.** Challenge assumptions, explore new tools, and deepen my technical understanding.

I value clear reasoning, technical consistency, and solutions that serve a real purpose.

## Beyond the code

I particularly enjoy problems where **logic, constraints, and practical usefulness**
come together.

I prefer understanding why a solution works rather than simply reproducing it.
For me, good engineering is not about adding layers of complexity:
it is about finding the simplest solution that correctly addresses the problem.

That means asking questions such as:

- Is this solution actually necessary?
- Can the same result be achieved with less complexity?
- Will another developer understand this code?
- What happens when the system encounters an unexpected situation?
- How can we verify that the change works as intended?

These questions guide the way I approach software development and technical learning.
